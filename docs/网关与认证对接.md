# Nova Cloud 前端 ↔ 网关 / 认证对接说明

## 1. 总体拓扑

```
浏览器 (nova-cloud-views :3100)
    │  /api/**
    ▼
Vite Dev Proxy / Nginx
    │
    ▼
Spring Cloud Gateway (:8080)
    ├── /auth/**     → nova-auth
    ├── /system/**   → nova-system
    ├── /file/**     → nova-file
    ├── /monitor/**  → nova-monitor
    ├── /search/**   → nova-search
    └── /job/**      → nova-job
```

开发环境配置见 `.env.development`：

```env
VITE_PROXY = [["/api","http://localhost:8080"],...]
VITE_GLOB_API_URL=/api
VITE_GLOB_DOMAIN_URL=http://localhost:8080
```

## 2. 认证约定

### 请求头

| Header | 说明 |
|--------|------|
| `Authorization` | `Bearer <access_token>`（默认开启） |
| `X-Access-Token` | 同 token，兼容旧组件/上传场景 |
| `X-Tenant-Id` | 多租户 ID |
| `X-TIMESTAMP` / `X-Sign` | Jeecg 风格签名（可按后端要求关闭） |

实现位置：`src/utils/http/axios/index.ts`

### 登录流程（现状 → 目标）

1. **现状（Mock / 兼容）**：`POST /sys/login`，返回 `{ token, userInfo }`
2. **目标（Nova Auth）**：`POST /auth/login`，返回 `{ accessToken, refreshToken, expiresIn, userInfo }`

切换开关：`src/api/nova/paths.ts` → `USE_NOVA_AUTH = true`

封装：`src/api/nova/auth.ts`

### Token 存储

沿用 Jeecg 规范，存于 localStorage（`TOKEN_KEY`），见 `src/utils/auth`。

后端 OAuth2/JWT 就绪后，可在 `userStore` 中同时保存 `refreshToken`，并用 `novaRefreshTokenApi` 续期。

## 3. 统一响应体

前端 `transformRequestHook` 已兼容两种格式：

```json
// 推荐（Nova）
{ "code": 200, "data": {}, "message": "ok", "success": true }

// 兼容（Jeecg）
{ "code": 0, "result": {}, "message": "ok", "success": true }
```

- 成功码：`200` 或 `0`
- 业务数据：优先 `data`，否则 `result`
- 提示文案：优先 `message`，否则 `msg`
- `401`：清 token 并跳转登录

类型定义：`types/axios.d.ts`

## 4. 权限与菜单

权限模式默认 **BACK**（`projectSetting.permissionMode`）：

1. 登录成功拿到 token
2. 拉取用户信息 + 权限码 + 后端菜单
3. `permissionStore` 动态 `addRoute`

后端菜单字段建议继续兼容 Jeecg 结构（`component`、`path`、`meta`、`children`），这样 Layout / 动态路由几乎不用改。

## 5. 后端落地检查清单

- [ ] Gateway 统一入口 `:8080`，剥离前缀或保留 `/api`
- [ ] nova-auth 提供登录 / 刷新 / 用户信息 / 权限码
- [ ] nova-system 提供用户/角色/菜单/字典 CRUD
- [ ] CORS 或同域反代（生产建议 Nginx 同域 `/api`）
- [ ] 将 `USE_NOVA_AUTH` 改为 `true`，关闭 `VITE_USE_MOCK`
- [ ] 如不需要 MD5 签名，后端忽略或前端去掉 `X-Sign` 相关 header

## 6. 组件使用规范（Jeecg 风格）

```vue
<script lang="ts" setup>
  import { BasicTable, useTable } from '/@/components/Table';
  import { BasicForm, useForm } from '/@/components/Form';
  import { useModal } from '/@/components/Modal';
  import { defHttp } from '/@/utils/http/axios';
</script>
```

全局已注册：`Icon`、`AIcon`、`Button`、`Tinymce`、Online 查询组件等（`registerGlobComp.ts`）。
